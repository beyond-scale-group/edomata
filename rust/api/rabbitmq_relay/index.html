Distributing outbox notifications to RabbitMQ: an event-sourced account service writes to PostgreSQL, and an OutboxRelay publishes the outbox to a RabbitMQ exchange through edomata-rabbitmq (publisher confirms, persistent messages, the stream id as routing key).

AMQP_URL=amqp://guest:guest@localhost:5672/%2f cargo run -p edomata-examples --features rabbitmq --bin rabbitmq_relay
