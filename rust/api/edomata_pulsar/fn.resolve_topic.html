Expand description

Resolves a topic to a full Pulsar topic name.

  • a full URL (persistent://tenant/namespace/topic, or non-persistent://...) is validated and returned as it is;
  • a short name is sanitized (sanitize_topic) and placed in the given tenant and namespace as a persistent topic.
use edomata_pulsar::resolve_topic;

assert_eq!(
    resolve_topic("accounts", "acme", "prod").unwrap(),
    "persistent://acme/prod/accounts"
);
assert_eq!(
    resolve_topic("persistent://other/ns/orders", "acme", "prod").unwrap(),
    "persistent://other/ns/orders"
);
assert!(resolve_topic("persistent://missing-parts", "acme", "prod").is_err());

§Errors

InvalidTopic when a URL has an unknown scheme or is not exactly scheme://tenant/namespace/topic with three non-empty parts.
