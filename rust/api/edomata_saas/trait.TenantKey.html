Expand description

A tenant identifier as the database sees it. The tenant id type is the one thing a project chooses (a string, a UUID…): implement this trait for it. TenantId, String and &str already implement it.

The key is validated by RlsAccessPolicy::tenant_access (not empty, no /, no NUL), so an implementation need not check it.

use edomata_saas::TenantKey;

struct OrgNumber(u64);

impl TenantKey for OrgNumber {
    fn tenant_key(&self) -> String {
        format!("org{}", self.0)
    }
}
assert_eq!(OrgNumber(7).tenant_key(), "org7");
