Expand description

Extracts tenant and owner from a state so that tenant-aware drivers can populate tenant_id / owner_id columns. Mirrors Scala’s TenantExtractor[S] typeclass, implemented on the state type itself.

CrudState implements it (None for NonExistent); implement it for your own state type to use it with edomata-saas-sqlx.

use edomata_saas::{CrudState, TenantExtractor};

let (tenant, owner) = CrudState::active("acme", "alice", ()).tenant_and_owner().unwrap();
assert_eq!((tenant.value(), owner.value()), ("acme", "alice"));
assert!(CrudState::<()>::NonExistent.tenant_and_owner().is_none());
