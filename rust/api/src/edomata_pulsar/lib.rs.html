1//! # Edomata Pulsar
2//!
3//! A [`Publisher`] for `edomata-broker` relays backed by the
4//! [`pulsar`] client (Apache Pulsar, including the managed add-on of Clever
5//! Cloud):
6//!
7//! - one Pulsar producer per topic, created lazily and cached; a producer
8//!   (or the whole connection) that fails is dropped so that the next
9//!   `publish` recreates it;
10//! - the stream id is the message key, which keeps per-stream ordering (also
11//!   on partitioned topics: the producer routes by key);
12//! - the topic is chosen by a function of the message (default: one topic
13//!   per relay source, i.e. per aggregate namespace); short names are placed
14//!   in the configured tenant and namespace, full
15//!   `persistent://<tenant>/<namespace>/<topic>` URLs are used as they are;
16//! - the message id and metadata travel as message properties (see
17//!   `edomata_broker::headers`).
18//!
19//! `publish` returns only after the broker acknowledged every message of the
20//! batch (a send receipt each); the relay marks outbox items as sent after
21//! that, so delivery is at-least-once and consumers deduplicate on the
22//! `edomata-id` property.
23//!
24//! Errors are classified for the relay: invalid topics, authentication and
25//! authorization failures, rejected topics and messages larger than the
26//! configured maximum are [`PublishError::Permanent`]; everything else
27//! (connection lost, timeouts, broker not ready...) is
28//! [`PublishError::Transient`] and retried. When unsure the error is
29//! transient.
30//!
31//! ## Where it fits
32//!
33//! `edomata-pulsar` depends only on `edomata-core` and `edomata-broker`: it
34//! is one [`Publisher`] implementation for the broker-agnostic
35//! [`OutboxRelay`](edomata_broker::OutboxRelay) and
36//! [`JournalRelay`](edomata_broker::JournalRelay). Applications that do not
37//! use Pulsar don't depend on it. It has no Scala counterpart. The
38//! [`pulsar`] crate is re-exported for its configuration and error types.
39//!
40//! ## Limits of a shared namespace
41//!
42//! A Pulsar producer belongs to one topic, so the number of distinct topics
43//! your topic function produces is the number of producers this publisher
44//! keeps. Managed offerings cap them: Clever Cloud documents at most 100
45//! topics per namespace and 100 producers per topic. Prefer
46//! [`with_fixed_topic`](PulsarPublisherBuilder::with_fixed_topic) or a
47//! function with a bounded range; never derive the topic from a stream id.
48//!
49//! ## Example
50//!
51//! An outbox relay publishing to one Pulsar topic with token authentication
52//! over TLS (the connection is made at the first publish, not at build time):
53//!
54//! ```no_run
55//! use std::sync::Arc;
56//!
57//! use edomata_backend::eventsourcing::Backend;
58//! use edomata_broker::postgres::LeaderLock;
59//! use edomata_broker::{CancellationToken, MessageEncoder, OutboxRelay, RelayConfig};
60//! use edomata_core::*;
61//! use edomata_pulsar::PulsarPublisher;
62//! use edomata_sqlx::SqlxDriver;
63//!
64//! struct Counter;
65//! impl DomainModel for Counter {
66//!     type State = i32; type Event = i32; type Rejection = String;
67//!     fn initial(&self) -> i32 { 0 }
68//!     fn transition(&self, e: &i32, s: i32) -> Result<i32, NonEmpty<String>> { Ok(s + e) }
69//! }
70//!
71//! # async fn example(pool: sqlx::PgPool) -> Result<(), Box<dyn std::error::Error>> {
72//! let backend = Backend::builder(Counter, Counter.dsl::<i32, String>())
73//!     .driver(SqlxDriver::for_namespace("counters", pool.clone()).await?)
74//!     .build_default()
75//!     .await?;
76//!
77//! let publisher = PulsarPublisher::builder("pulsar+ssl://broker.example.com:6651")
78//!     .with_token("eyJ...")
79//!     .with_namespace("my-tenant", "my-namespace")
80//!     .with_fixed_topic("counters-notifications")
81//!     .build()?;
82//!
83//! let relay = OutboxRelay::new(
84//!     Arc::clone(backend.outbox()),
85//!     Arc::new(publisher),
86//!     MessageEncoder::<String>::serde(),
87//!     RelayConfig::new("counters"),
88//! )
89//! .wake_on(backend.updates().outbox());
90//!
91//! relay
92//!     .run_as_leader(LeaderLock::new(pool, "counters"), CancellationToken::new())
93//!     .await?;
94//! # Ok(()) }
95//! ```
96//!
97//! ## Clever Cloud
98//!
99//! The Pulsar add-on injects `ADDON_PULSAR_BINARY_URL`, `ADDON_PULSAR_TOKEN`,
100//! `ADDON_PULSAR_TENANT` and `ADDON_PULSAR_NAMESPACE`;
101//! [`PulsarPublisherBuilder::from_clever_env`] reads them.
102//!
103//! ## Feature flags
104//!
105//! This crate has no Cargo feature flags of its own. The `pulsar` client is
106//! built with TLS through `rustls` (no system OpenSSL), without OAuth2
107//! authentication and without message compression; building it needs the
108//! `protoc` protobuf compiler.

184/// Publishes broker messages to Apache Pulsar.
185///
186/// Each [`BrokerMessage`] becomes one Pulsar message: the topic comes from
187/// the topic function ([`default_topic`] unless set on the builder) and
188/// [`resolve_topic`], the key is the stream id, the payload is the encoded
189/// payload and every [`BrokerMessage::headers`] entry is a message property.
190/// `publish` enqueues the whole batch, then waits for every send receipt; it
191/// fails with the first failed receipt, after which the relay republishes the
192/// batch (messages already acknowledged are delivered again: at-least-once).
193///
194/// Build it with [`PulsarPublisher::builder`]. Neither building it nor
195/// creating the builder contacts the broker: the connection and the
196/// producers are created at the first `publish`, so a wrong address shows up
197/// as transient publish failures.
198///
199/// Concurrent `publish` calls are serialized while their messages are
200/// enqueued (one mutex around the producers) and wait for their receipts
201/// concurrently.
202pub struct PulsarPublisher {
203    config: ClientConfig,
204    topic: Arc<TopicFn>,
205    tenant: String,
206    namespace: String,
207    send_timeout: Duration,
208    max_message_size: usize,
209    state: Mutex<State>,
210}

250#[derive(Default)]
251struct State {
252    client: Option<Pulsar<TokioExecutor>>,
253    producers: HashMap<String, (u64, Producer<TokioExecutor>)>,
254    next_id: u64,
255}
256
257impl State {
258    /// Drops the producer of `topic` if it is still the instance `id` (a
259    /// concurrent publish may already have replaced it).
260    fn drop_producer(&mut self, topic: &str, id: u64) {
261        if self.producers.get(topic).is_some_and(|(i, _)| *i == id) {
262            self.producers.remove(topic);
263        }
264    }
265
266    /// Drops the connection and every producer.
267    fn reset(&mut self) {
268        self.producers.clear();
269        self.client = None;
270    }
271
272    /// The reaction to a failure of the producer `id` of `topic`.
273    fn invalidate(&mut self, topic: &str, id: u64, error: &Error) {
274        if resets_connection(error) {
275            tracing::warn!(%error, "pulsar connection failed: dropping the client and its producers");
276            self.reset();
277        } else {
278            tracing::warn!(%error, topic, "pulsar producer failed: dropping it");
279            self.drop_producer(topic, id);
280        }
281    }
282}

335impl PulsarPublisher {
336    /// A builder for the given service URL (`pulsar://host:port`, or
337    /// `pulsar+ssl://host:port` for TLS) with the [`default_topic`], the
338    /// `public/default` namespace, no authentication, a 30-second send
339    /// timeout and [`DEFAULT_MAX_MESSAGE_SIZE`].
340    pub fn builder(service_url: impl Into<String>) -> PulsarPublisherBuilder {
341        PulsarPublisherBuilder {
342            config: ClientConfig {
343                service_url: service_url.into(),
344                authentication: None,
345                certificate_chain: None,
346                allow_insecure_connection: None,
347                tls_hostname_verification: None,
348            },
349            topic: Arc::new(default_topic),
350            tenant: DEFAULT_TENANT.to_string(),
351            namespace: DEFAULT_NAMESPACE.to_string(),
352            send_timeout: Duration::from_secs(30),
353            max_message_size: DEFAULT_MAX_MESSAGE_SIZE,
354        }
355    }
356
357    /// The full topic name `message` goes to: the topic function's choice
358    /// resolved by [`resolve_topic`] against the configured tenant and
359    /// namespace.
360    ///
361    /// # Errors
362    ///
363    /// [`InvalidTopic`] when the function returned a malformed topic URL.
364    pub fn topic_for(&self, message: &BrokerMessage) -> Result<String, InvalidTopic> {
365        resolve_topic(&(self.topic)(message), &self.tenant, &self.namespace)
366    }
367
368    /// Closes the producers and drops the connection. Call it before
369    /// shutting down; `publish` already waits for its own batch, so nothing
370    /// is lost by not calling it. The publisher stays usable: the next
371    /// `publish` reconnects.
372    pub async fn close(&self) {
373        let mut state = self.state.lock().await;
374        let producers = std::mem::take(&mut state.producers);
375        state.client = None;
376        drop(state);
377        for (topic, (_, mut producer)) in producers {
378            if let Err(error) = producer.close().await {
379                tracing::debug!(%error, topic, "closing a pulsar producer failed");
380            }
381        }
382    }
383
384    async fn connect(&self) -> Result<Pulsar<TokioExecutor>, Error> {
385        let config = &self.config;
386        let mut builder = Pulsar::builder(config.service_url.clone(), TokioExecutor);
387        if let Some(authentication) = &config.authentication {
388            builder = builder.with_auth(authentication.clone());
389        }
390        if let Some(chain) = &config.certificate_chain {
391            builder = builder.with_certificate_chain(chain.clone());
392        }
393        if let Some(allow) = config.allow_insecure_connection {
394            builder = builder.with_allow_insecure_connection(allow);
395        }
396        if let Some(enabled) = config.tls_hostname_verification {
397            builder = builder.with_tls_hostname_verification_enabled(enabled);
398        }
399        builder.build().await
400    }
401
402    /// Enqueues `message` on the (cached or new) producer of `topic`; returns
403    /// the producer instance and the receipt to await.
404    async fn enqueue(
405        &self,
406        state: &mut State,
407        topic: &str,
408        message: Message,
409    ) -> Result<(u64, SendFuture), (u64, Error)> {
410        if !state.producers.contains_key(topic) {
411            if state.client.is_none() {
412                state.client = Some(self.connect().await.map_err(|e| (0, e))?);
413            }
414            let client = state.client.as_ref().expect("client was just created");
415            let producer = client
416                .producer()
417                .with_topic(topic)
418                .with_options(producer_options())
419                .build()
420                .await
421                .map_err(|e| (0, e))?;
422            state.next_id += 1;
423            state
424                .producers
425                .insert(topic.to_string(), (state.next_id, producer));
426        }
427        let (id, producer) = state
428            .producers
429            .get_mut(topic)
430            .expect("producer was just created");
431        let id = *id;
432        producer
433            .send_non_blocking(message)
434            .await
435            .map(|receipt| (id, receipt))
436            .map_err(|e| (id, e))
437    }
438}

440/// The options of every producer.
441///
442/// - no batching: one message, one receipt, in send order;
443/// - `block_queue_if_full`: a large batch waits for room in the producer's
444///   queue instead of failing with `SlowDown`;
445/// - round-robin *with a key* routes by a hash of the key, so that on a
446///   partitioned topic a stream always lands in the same partition (without
447///   the policy the client spreads messages round-robin and ignores the key).
448fn producer_options() -> ProducerOptions {
449    ProducerOptions {
450        block_queue_if_full: true,
451        routing_policy: Some(RoutingPolicy::RoundRobin),
452        ..ProducerOptions::default()
453    }
454}

456/// The default topic: the relay source with every character outside
457/// `[A-Za-z0-9._-]` replaced by `-` (a safe subset of Pulsar's topic name
458/// alphabet), that is one topic per relay source, see [`sanitize_topic`].
459pub fn default_topic(message: &BrokerMessage) -> String {
460    sanitize_topic(&message.source)
461}
462
463/// Makes a string a valid Pulsar topic name (the part after the namespace):
464/// every character outside `[A-Za-z0-9._-]` becomes `-` (a safe subset of
465/// the alphabet Pulsar accepts), and an empty name becomes `"edomata"`.
466///
467/// ```
468/// use edomata_pulsar::sanitize_topic;
469///
470/// assert_eq!(sanitize_topic("accounts"), "accounts");
471/// assert_eq!(sanitize_topic("billing/invoices:v1"), "billing-invoices-v1");
472/// assert_eq!(sanitize_topic(""), "edomata");
473/// ```
474pub fn sanitize_topic(name: &str) -> String {
475    let topic: String = name
476        .chars()
477        .map(|c| {
478            if c.is_ascii_alphanumeric() || matches!(c, '.' | '_' | '-') {
479                c
480            } else {
481                '-'
482            }
483        })
484        .collect();
485    if topic.is_empty() {
486        "edomata".to_string()
487    } else {
488        topic
489    }
490}

492/// Resolves a topic to a full Pulsar topic name.
493///
494/// - a full URL (`persistent://tenant/namespace/topic`, or
495///   `non-persistent://...`) is validated and returned as it is;
496/// - a short name is sanitized ([`sanitize_topic`]) and placed in the given
497///   tenant and namespace as a persistent topic.
498///
499/// ```
500/// use edomata_pulsar::resolve_topic;
501///
502/// assert_eq!(
503///     resolve_topic("accounts", "acme", "prod").unwrap(),
504///     "persistent://acme/prod/accounts"
505/// );
506/// assert_eq!(
507///     resolve_topic("persistent://other/ns/orders", "acme", "prod").unwrap(),
508///     "persistent://other/ns/orders"
509/// );
510/// assert!(resolve_topic("persistent://missing-parts", "acme", "prod").is_err());
511/// ```
512///
513/// # Errors
514///
515/// [`InvalidTopic`] when a URL has an unknown scheme or is not exactly
516/// `scheme://tenant/namespace/topic` with three non-empty parts.
517pub fn resolve_topic(topic: &str, tenant: &str, namespace: &str) -> Result<String, InvalidTopic> {
518    let invalid = |reason| InvalidTopic {
519        topic: topic.to_string(),
520        reason,
521    };
522    match topic.split_once("://") {
523        None => Ok(format!(
524            "persistent://{tenant}/{namespace}/{}",
525            sanitize_topic(topic)
526        )),
527        Some((scheme, rest)) => {
528            if !matches!(scheme, "persistent" | "non-persistent") {
529                return Err(invalid("the scheme must be persistent or non-persistent"));
530            }
531            let parts: Vec<&str> = rest.split('/').collect();
532            if parts.len() != 3 || parts.iter().any(|p| p.is_empty()) {
533                return Err(invalid("expected scheme://tenant/namespace/topic"));
534            }
535            Ok(topic.to_string())
536        }
537    }
538}

542    /// add-on of Clever Cloud injects: `ADDON_PULSAR_BINARY_URL` (service

554    /// [`from_clever_env`](Self::from_clever_env) with a custom variable
555    /// lookup.
556    fn from_env_with(get: impl Fn(&str) -> Option<String>) -> Result<Self, BuildError> {
557        let var = |name: &'static str| {
558            get(name)
559                .map(|v| v.trim().to_string())
560                .filter(|v| !v.is_empty())
561                .ok_or(BuildError::MissingEnv(name))
562        };
563        let url = var("ADDON_PULSAR_BINARY_URL")?;
564        let token = var("ADDON_PULSAR_TOKEN")?;
565        let tenant = var("ADDON_PULSAR_TENANT")?;
566        let namespace = var("ADDON_PULSAR_NAMESPACE")?;
567        Ok(PulsarPublisher::builder(url)
568            .with_token(token)
569            .with_namespace(tenant, namespace))
570    }

600    /// Chooses the topic per message: a short name or a full topic URL (see
601    /// [`resolve_topic`]). The function is called once per message; keep it
602    /// deterministic so that a stream always goes to the same topic

658    /// Creates the publisher. It does not contact the broker.
659    ///
660    /// # Errors
661    ///
662    /// [`BuildError`] when the service URL does not start with `pulsar://`
663    /// or `pulsar+ssl://`, or the tenant or namespace is empty or contains a
664    /// `/`.
665    pub fn build(self) -> Result<PulsarPublisher, BuildError> {
666        let url = &self.config.service_url;
667        let secure = url.starts_with("pulsar+ssl://");
668        let host = url
669            .strip_prefix("pulsar+ssl://")
670            .or_else(|| url.strip_prefix("pulsar://"))
671            .unwrap_or_default();
672        if host.is_empty() {
673            return Err(BuildError::InvalidServiceUrl(url.clone()));
674        }
675        let bad = |s: &str| s.is_empty() || s.contains('/');
676        if bad(&self.tenant) || bad(&self.namespace) {
677            return Err(BuildError::InvalidNamespace {
678                tenant: self.tenant,
679                namespace: self.namespace,
680            });
681        }
682        if !secure && self.config.authentication.is_some() {
683            tracing::warn!(
684                "pulsar authentication over a plain pulsar:// url: credentials are not encrypted"
685            );
686        }
687        Ok(PulsarPublisher {
688            config: self.config,
689            topic: self.topic,
690            tenant: self.tenant,
691            namespace: self.namespace,
692            send_timeout: self.send_timeout,
693            max_message_size: self.max_message_size,
694            state: Mutex::new(State::default()),
695        })
696    }
697}

699/// The message properties of a broker message: the id and every metadata
700/// header of [`BrokerMessage::headers`].
701fn properties_of(message: &BrokerMessage) -> HashMap<String, String> {
702    message.headers().into_iter().collect()
703}
704
705/// The Pulsar message for a broker message: payload, stream id as key,
706/// headers as properties, the message time as event time.
707fn pulsar_message(message: &BrokerMessage) -> Message {
708    Message {
709        payload: message.payload.clone(),
710        properties: properties_of(message),
711        partition_key: Some(message.stream_id.clone()),
712        event_time: u64::try_from(message.time.timestamp_millis()).ok(),
713        ..Message::default()
714    }
715}
716
717/// The Pulsar server error behind `error`, when there is one.
718fn server_error(error: &Error) -> Option<ServerError> {
719    match error {
720        Error::Connection(ConnectionError::PulsarError(kind, _))
721        | Error::Producer(ProducerError::Connection(ConnectionError::PulsarError(kind, _)))
722        | Error::ServiceDiscovery(ServiceDiscoveryError::Query(kind, _)) => *kind,
723        Error::Producer(ProducerError::Batch(inner)) => server_error(inner),
724        _ => None,
725    }
726}
727
728/// Whether a failure says that retrying the same batch can never succeed.
729fn is_permanent(error: &Error) -> bool {
730    matches!(
731        server_error(error),
732        Some(
733            ServerError::InvalidTopicName
734                | ServerError::AuthenticationError
735                | ServerError::AuthorizationError
736                | ServerError::NotAllowedError
737                | ServerError::IncompatibleSchema
738                | ServerError::UnsupportedVersionError
739                | ServerError::TopicTerminatedError
740        )
741    )
742}
743
744/// Whether a failure is about the connection rather than one producer: the
745/// client is rebuilt too. A server error answers on a healthy connection.
746fn resets_connection(error: &Error) -> bool {
747    match error {
748        Error::Connection(ConnectionError::PulsarError(..))
749        | Error::Producer(ProducerError::Connection(ConnectionError::PulsarError(..)))
750        | Error::ServiceDiscovery(ServiceDiscoveryError::Query(..)) => false,
751        Error::Connection(_)
752        | Error::Producer(
753            ProducerError::Connection(_) | ProducerError::Io(_) | ProducerError::Closed,
754        )
755        | Error::ServiceDiscovery(_) => true,
756        Error::Producer(ProducerError::Batch(inner)) => resets_connection(inner),
757        _ => false,
758    }
759}
760
761fn classify(error: Error) -> PublishError {
762    if is_permanent(&error) {
763        PublishError::Permanent(Box::new(error))
764    } else {
765        PublishError::Transient(Box::new(error))
766    }
767}

769#[async_trait]
770impl Publisher for PulsarPublisher {
771    async fn publish(&self, batch: &NonEmpty<BrokerMessage>) -> Result<(), PublishError> {
772        // Validate everything before any I/O: a message that can never be
773        // sent must not be retried, and nothing is half-published for it.
774        let mut prepared = Vec::with_capacity(batch.len());
775        for message in batch.iter() {
776            if message.payload.len() > self.max_message_size {
777                return Err(PublishError::Permanent(
778                    format!(
779                        "message {} has a {}-byte payload, above the {}-byte maximum",
780                        message.id,
781                        message.payload.len(),
782                        self.max_message_size
783                    )
784                    .into(),
785                ));
786            }
787            let topic = self
788                .topic_for(message)
789                .map_err(|e| PublishError::Permanent(Box::new(e)))?;
790            prepared.push((topic, pulsar_message(message)));
791        }
792
793        // Enqueue in batch order (per-producer order is the send order),
794        // under the lock, then wait for the receipts without it.
795        let mut pending: Vec<(String, u64, SendFuture)> = Vec::with_capacity(prepared.len());
796        let enqueued = {
797            let mut state = self.state.lock().await;
798            let state = &mut *state;
799            let enqueue_all = async {
800                for (topic, message) in prepared {
801                    match self.enqueue(state, &topic, message).await {
802                        Ok((id, receipt)) => pending.push((topic, id, receipt)),
803                        Err((id, error)) => {
804                            state.invalidate(&topic, id, &error);
805                            return Err(classify(error));
806                        }
807                    }
808                }
809                Ok(())
810            };
811            match tokio::time::timeout(self.send_timeout, enqueue_all).await {
812                Ok(result) => result,
813                Err(_) => {
814                    state.reset();
815                    Err(PublishError::transient(format!(
816                        "timed out after {:?} connecting to Pulsar or enqueueing the batch",
817                        self.send_timeout
818                    )))
819                }
820            }
821        };
822        enqueued?;
823
824        let producers: Vec<(String, u64)> = pending
825            .iter()
826            .map(|(topic, id, _)| (topic.clone(), *id))
827            .collect();
828        let acknowledged = async {
829            for (topic, id, receipt) in pending {
830                let receipt = receipt.await.map_err(|e| (topic.clone(), id, e))?;
831                tracing::trace!(topic, ?receipt.message_id, "pulsar delivery acknowledged");
832            }
833            Ok::<(), (String, u64, Error)>(())
834        };
835        match tokio::time::timeout(self.send_timeout, acknowledged).await {
836            Ok(Ok(())) => Ok(()),
837            Ok(Err((topic, id, error))) => {
838                self.state.lock().await.invalidate(&topic, id, &error);
839                Err(classify(error))
840            }
841            Err(_) => {
842                // Unknown which producer is stuck: drop every one of the batch.
843                let mut state = self.state.lock().await;
844                for (topic, id) in &producers {
845                    state.drop_producer(topic, *id);
846                }
847                Err(PublishError::transient(format!(
848                    "timed out after {:?} waiting for the broker to acknowledge the batch",
849                    self.send_timeout
850                )))
851            }
852        }
853    }
854}
