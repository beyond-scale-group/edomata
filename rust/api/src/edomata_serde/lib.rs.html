1//! # Edomata serde codecs
2//!
3//! The one payload codec of the Rust port, replacing the Circe, jsoniter and
4//! uPickle codec modules: [`SerdeCodec<T>`] implements
5//! [`edomata_backend::Codec`] for any `T: Serialize + DeserializeOwned` with
6//! `serde_json`.
7//!
8//! Payloads are stored as **`jsonb` by default** (queryable with `->`, `@>`
9//! and GIN indexes); `json` and `bytea` are supported for tables that already
10//! use them. JSON is written straight to bytes (`serde_json::to_writer`)
11//! and, with the `sqlx` feature, the [`pg`] module puts those bytes on the
12//! wire in PostgreSQL's binary `jsonb` format (version byte + UTF-8 JSON)
13//! without any intermediate `String` or `serde_json::Value`.
14//!
15//! ```
16//! use edomata_backend::{Codec, PayloadFormat};
17//! use edomata_serde::SerdeCodec;
18//! use serde::{Deserialize, Serialize};
19//!
20//! #[derive(Debug, PartialEq, Serialize, Deserialize)]
21//! enum Event { Opened { owner: String }, Closed }
22//!
23//! let codec = SerdeCodec::<Event>::jsonb();
24//! assert_eq!(codec.format(), PayloadFormat::Jsonb);
25//! let bytes = codec.encode(&Event::Opened { owner: "bob".into() }).unwrap();
26//! assert_eq!(bytes, br#"{"Opened":{"owner":"bob"}}"#);
27//! assert_eq!(codec.decode(&bytes).unwrap(), Event::Opened { owner: "bob".into() });
28//! ```
29//!
30//! ## Reading payloads written by Scala
31//!
32//! Circe (generic derivation), jsoniter-scala (including its `msgpack` codec,
33//! which writes JSON bytes) and uPickle JSON payloads are all JSON and can be
34//! read by choosing the matching `serde` enum representation:
35//!
36//! | Scala codec | JSON shape of an ADT case | serde representation |
37//! |-------------|---------------------------|----------------------|
38//! | Circe `generic.auto` | `{"Opened":{...}}`, `{"Closed":{}}`, `None` → `null` | default (externally tagged); parameterless cases as `Closed {}` |
39//! | jsoniter `JsonCodecMaker.make` | `{"type":"Opened",...}`, `{"type":"Closed"}`, `None` omitted | `#[serde(tag = "type")]` plus `#[serde(default, skip_serializing_if = "Option::is_none")]` on `Option` fields |
40//! | uPickle `ReadWriter.derived` | `{"$type":"Opened",...}`, `"Closed"`, `None` → `[]` / `Some(x)` → `[x]` | `#[serde(tag = "$type")]` inside an `#[serde(untagged)]` wrapper for bare-string cases, plus [`compat::upickle_option`] |
41//!
42//! The golden payload tests (`tests/golden_payloads.rs`) check these shapes
43//! against files written by the Scala codecs. uPickle's `msgpack` codec
44//! writes real MessagePack into `bytea`; those payloads cannot be read
45//! because `serde_json` is the only serializer.
46//!
47//! ## Where it fits
48//!
49//! `edomata-serde` depends only on `edomata-backend`, whose [`Codec`] trait
50//! it implements (and re-exports, with [`CodecError`] and
51//! [`PayloadFormat`]). It is the default codec of the PostgreSQL crates
52//! built on it: `edomata-sqlx` (whose drivers bind payloads through
53//! [`pg`]), `edomata-saas-sqlx`, `edomata-simple` and `edomata-e2e`.
54//!
55//! ## Feature flags
56//!
57//! - `sqlx` (enabled by default): the [`pg`] module, i.e. the PostgreSQL
58//!   wire types ([`pg::JsonbPayload`], [`pg::JsonPayload`],
59//!   [`pg::ByteaPayload`], [`pg::PgPayload`]) implementing sqlx's `Type`,
60//!   `Encode` and `Decode`. Disable default features to use
61//!   [`SerdeCodec`] without pulling in sqlx.
