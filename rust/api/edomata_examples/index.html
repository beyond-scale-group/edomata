Shared helpers for the examples (src/bin/*.rs), which are ports of the Scala programs under examples/src/main/scala/.

Every example connects to the PostgreSQL instance of the repository’s docker-compose.yml (or to DATABASE_URL) and can be run with cargo run -p edomata-examples --bin <name>.
