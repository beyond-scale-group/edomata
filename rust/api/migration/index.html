Port of examples/src/main/scala/MigrationExample.scala: evolving event schemas with journal migrations. Events stored in the journal are rewritten in place, like Flyway for event payloads.

Scenario, a product catalogue where:

  • V1 → V2: PriceUpdated gains a currency field (defaulting to “USD”)
  • V2 → V3: Created gains a description field (defaulting to “”)

Unlike the Scala example, this one also seeds a V1 journal first and reads it back with the V3 codec after the migrations ran.

cargo run -p edomata-examples --bin migration
