Distributing outbox notifications to Kafka: an event-sourced account service writes to PostgreSQL, and an OutboxRelay publishes the outbox to a Kafka topic through edomata-kafka, woken up by the backend’s signal (or by LISTEN/NOTIFY when the relay runs in another process).

KAFKA_BOOTSTRAP=localhost:9092 cargo run -p edomata-examples --features kafka --bin kafka_relay
