pub async fn retry<T, F, Fut>(
    max: u32,
    wait: Duration,
    f: F,
) -> Result<T, BackendError>
where
    F: FnMut() -> Fut,
    Fut: Future<Output = Result<T, BackendError>>,
Expand description

Runs f up to max times while it fails with BackendError::VersionConflict, waiting wait (doubling each time, plus a random jitter of up to 500 ms) between attempts. When the last attempt still conflicts, fails with BackendError::MaxRetryExceeded. Any other error is returned as is.

Command handlers use it with their RetryConfig; call it directly to retry your own read-decide-write loops. Waiting uses tokio::time, so it needs a Tokio runtime with the time driver enabled.

§Errors

BackendError::MaxRetryExceeded after max conflicting attempts, or the first error that is not a BackendError::VersionConflict.

use std::time::Duration;
use edomata_backend::{retry, BackendError};

// Conflicts twice, then succeeds on the third attempt.
let mut attempts = 0;
let result = retry(3, Duration::from_millis(10), || {
    attempts += 1;
    let outcome = if attempts < 3 { Err(BackendError::VersionConflict) } else { Ok(attempts) };
    async move { outcome }
})
.await;
assert_eq!(result, Ok(3));

// Always conflicting: gives up after `max` attempts.
let result: Result<(), _> = retry(2, Duration::ZERO, || async { Err(BackendError::VersionConflict) }).await;
assert_eq!(result, Err(BackendError::MaxRetryExceeded));
