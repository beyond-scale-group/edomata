Expand description

Builds storages for CQRS aggregates. Mirrors Scala’s StorageDriver[F, Codec[_], Handler[_]].

Codec<T> is the codec a driver needs for payloads of type T and Handler<N> is the driver-specific hook that runs inside the save transaction for every batch of notifications (used to maintain projections atomically).
