Enum EdomatonResult 

Source 
pub enum EdomatonResult<S, E, R, N> {
    Accepted {
        new_state: S,
        events: NonEmpty<E>,
        notifications: Vec<N>,
    },
    Indecisive {
        notifications: Vec<N>,
    },
    Rejected {
        notifications: Vec<N>,
        reasons: NonEmpty<R>,
    },
    Conflicted {
        reasons: NonEmpty<R>,
    },
}
Expand description

Outcome of executing an Edomaton against a DomainModel, produced by DomainCompiler::execute and Edomaton::execute.

Variants§

§

Accepted

Events were accepted and applied to the state.

Fields

§new_state: S

State after applying the events.

§events: NonEmpty<E>

The accepted events.

§notifications: Vec<N>

Notifications to publish.

§

Indecisive

The program neither accepted nor rejected.

§notifications: Vec<N>

Notifications to publish.

§

Rejected

The program rejected the command.

Fields

§notifications: Vec<N>

Notifications to publish.

§reasons: NonEmpty<R>

Rejection reasons.

§

Conflicted

The program accepted events that the model refuses to apply: the program and the model disagree.

Fields

§reasons: NonEmpty<R>

Rejection reasons reported by the model.
