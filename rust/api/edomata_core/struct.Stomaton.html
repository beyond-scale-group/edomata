Struct Stomaton 

Source 
pub struct Stomaton<Env, S, R, N, A> { /* private fields */ }
Expand description

A state automaton: a reusable, asynchronous program that reads an input (Env) and the current state, produces a new state and an output, and optionally publishes notifications. Unlike Edomaton it has no domain events: the state is stored directly.

§Type parameters

  • Env – input type, usually a CommandMessage
  • S – state type
  • R – rejection type
  • N – notification type
  • A – output type
use edomata_core::{Stomaton, nonempty};

let inc: Stomaton<i32, i32, &str, &str, i32> = Stomaton::context()
    .and_then(|by| Stomaton::modify(move |s| s + by))
    .publish(["incremented"]);

let out = futures::executor::block_on(inc.run(5, 10));
assert_eq!(out.result, Ok((15, 15)));
assert_eq!(out.notifications, vec!["incremented"]);

pub fn and_then<B, F>(self, f: F) -> Stomaton<Env, S, R, N, B>
where Env: Clone, B: Send + 'static, F: Fn(A) -> Stomaton<Env, S, R, N, B> + Send + Sync + 'static,

Binds another stomaton to this one.

The next stomaton runs with the state produced by this one. Notifications of both are kept in order; a rejection of this stomaton short-circuits and keeps its notifications.

use edomata_core::{Stomaton, nonempty};

let program: Stomaton<(), i32, &str, (), i32> = Stomaton::modify(|s| s + 1)
    .and_then(|s| if s > 1 { Stomaton::reject("too big") } else { Stomaton::modify(|s| s * 10) });

let ok = futures::executor::block_on(program.run((), 0));
assert_eq!(ok.result, Ok((10, 10)));
let ko = futures::executor::block_on(program.run((), 5));
assert_eq!(ko.result, Err(nonempty!["too big"]));

pub fn decide_state<F>(self, f: F) -> Stomaton<Env, S, R, N, S>
where S: Clone, F: Fn(S) -> Result<S, NonEmpty<R>> + Send + Sync + 'static,

Decides on a new state from the resulting state; the output becomes the new state. An Err rejects the whole program.

use edomata_core::{NonEmpty, Stomaton};

let withdraw: Stomaton<u32, u32, &str, (), u32> = Stomaton::unit().decide_state(|balance: u32| {
    balance.checked_sub(30).ok_or_else(|| NonEmpty::new("insufficient funds"))
});
assert_eq!(futures::executor::block_on(withdraw.run(0, 100)).result, Ok((70, 70)));
assert!(futures::executor::block_on(withdraw.run(0, 10)).result.is_err());
