Porting map: Scala modules and suites → Rust

This table is the contract of the Rust port (see docs/plans/rust-port.md at the repository root). Every Scala module and every Scala test suite is mapped to its Rust counterpart. Rows marked planned name the milestone that ports them; the port is complete when no row is left planned.
